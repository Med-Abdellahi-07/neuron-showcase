# Security

This repository is a public mirror of the private Neuron repository.

- **No production secrets.** API keys, tokens, service-role keys and `.env` files are not in this repository. They were also removed from the full commit history before publication. Environment variables are documented by name only in the README.
- **No production data.** No student, account, message or usage data is included. Screenshots were produced from a mock backend with fictional names.
- **No access to the live system.** The deployed application is limited to enrolled students and runs on separate infrastructure.

If you believe you have found a security issue in the code shown here, please open a private security advisory on this repository (Security tab, "Report a vulnerability") instead of a public issue.
